# DSH Bot UX 整改报告

## 结论

本轮 UX 整改覆盖聊天、线程切换、输入区、待回答/审批、Bot/群/例程编辑、通知/预算、记忆、搜索、空状态、加载失败、窄屏布局和键盘焦点。

功能面没有增加；QQ 通知保持默认关闭；会话、群、例程、记忆和设置数据未改动。

## 未完成的外部验证

由于用户要求不操作外接显示屏，本轮没有做真实鼠标点验。以下项目需要在笔记本屏幕上由用户确认：

1. 1024px 窗口和 125%/150% 缩放下的实际观感；
2. 真实点击「回到最新」是否立即回到底部；
3. 窄屏 Deck / 侧栏点击外部关闭；
4. Toast 是否仍与待回答卡片视觉重叠（现在已保证不拦截点击）；
5. 编辑器 Esc/未保存确认是否符合预期。

## 已知限制

- 静态守卫不能替代真实布局测量；
- 视觉问题需要截图或 DOM 命中测试；
- 本轮没有新增浏览器扩展、远程控制或自动点击能力。
